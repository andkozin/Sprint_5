# Sprint_5

# Автотесты для Stellar Burgers 
Автотесты для стенда [Stellar Burgers](https://stellarburgers.education-services.ru).  

### Регистрация

- **Успешная регистрация**  
  Проверить, что регистрация проходит при соблюдении требований к полям:
  - поле «Имя» — не пустое;
  - в поле «Email» введён email в формате логин@домен 
  - пароль — не менее 6 символов.

- **Ошибка для некорректного пароля**  
  Проверить отображение ошибки при вводе пароля длиной менее 6 символов.

---

### Вход в аккаунт

Проверить вход в систему следующими способами:

- через кнопку **«Войти в аккаунт»** на главной странице;
- через кнопку **«Личный кабинет»**;
- через кнопку входа в **форме регистрации**;
- через кнопку входа в **форме восстановления пароля**.

---

### Переход в личный кабинет

- Проверить переход в личный кабинет по клику на кнопку **«Личный кабинет»**.

---

### Переход из личного кабинета в конструктор

Проверить корректность переходов:

- по клику на кнопку **«Конструктор»**;
- по клику на **логотип Stellar Burgers**.

---

### Выход из аккаунта

- Проверить выход из аккаунта по кнопке **«Выход»** в личном кабинете.

---

### Раздел «Конструктор»

Проверить работоспособность переходов к разделам внутри конструктора:

- **«Булки»**;
- **«Соусы»**;
- **«Начинки»**

## Реализации

- **Автономность** Каждый тест открывает браузер, выполняет сценарий и закрывает его через.
- **Генератор данных.** Email формируется по шаблону: `имя_фамилия_номер_когорты_3_цифры@домен` в generator.py
- **Вынос данных** URL — в url.py локаторы — в locators.py, помощь в регистрации — в reg_help.py
- **Фикстуры.** driver — фикстура с завершением сессии; authorized_user — для быстрого логина в тестах, где нужна авторизация.

---
## Покрытые 

- **Регистрация:** успешная регистрация, проверка ошибки при пароле короче 6 символов.
- **Вход:** Способы перехода к форме входа и последующий логин.
- **Навигация:** переход в личный кабинет, выход из аккаунта, переход в конструктор (через логотип и ссылку).
- **Конструктор:** переключение между вкладками «Булки», «Соусы», «Начинки».
